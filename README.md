# BMI Fitness Prediction System

This project predicts whether a person is fit or not based on BMI using Machine Learning.

## Technologies
- Python
- Scikit-learn
- Flask
- HTML

## Features
- Real-time prediction
- Web interface
- BMI calculation

## How to Run
1. Install dependencies
2. Run app.py
3. Open http://127.0.0.1:5000
